# 黄金ETF专属宏观数据

本目录只服务于`518600 广发黄金ETF`的Agent增量分析，不属于8只ETF行情清单，不进入冠军模型或B0207机械计算。

## 文件

- `美国10年TIPS实际收益率.csv`：美国财政部10年期TIPS实际收益率，单位为百分比。
- `美国10年市场隐含通胀.csv`：同日10年名义美债收益率减10年TIPS实际收益率，单位为百分比。
- `latest.json`：最新值以及前1、5、20个共同观测的变化。
- `美联储政策决议.csv`：2023至2025年全部24次FOMC政策决议、目标区间和官方声明来源。
- `黄金ETF_FOMC事件窗口.csv`：518600复权收盘价在FOMC声明日前后15个自然日的逐事件窗口。
- `黄金ETF_FOMC事件窗口汇总.json`：加息、降息、维持分组后的样本数、平均后15日涨跌和正负次数。
- `黄金外部证据登记.json`：FOMC、央行黄金需求、美元/人民币和国际黄金等带来源背景；未核实项目保持`unavailable`。
- `黄金事件观察清单_2026-09至11月.json`：9月4日、9月11日、9月15至16日及11月观察窗口的机器可读核对项。
- `黄金事件观察清单_2026-09至11月.md`：上述事件的人工说明、使用边界和明确排除内容。

## 更新

在项目根目录运行：

```powershell
python scripts/update_gold_macro_data.py --as-of YYYY-MM-DD --check
python scripts/update_gold_macro_data.py --as-of YYYY-MM-DD
python scripts/update_gold_fomc_data.py --as-of YYYY-MM-DD --check
python scripts/update_gold_fomc_data.py --as-of YYYY-MM-DD
```

默认保存2021年至指定截止日的共同有效观测。需要更长历史时可增加`--start-year`，最早允许2003年。

## 使用边界

- 美国日期为官方来源观测日，不代表该数据在同日中国市场收盘前已经可得。
- A股收盘后发布的美国数据只能进入发布后的下一次分析，禁止倒灌。
- 10年市场隐含通胀是通胀补偿，不是确定的未来CPI预测。
- 实际利率和隐含通胀必须与518600周K、日K、均线和成交量联合解释，不能单独触发交易。
- FOMC窗口固定以声明前最后一个A股有效收盘为基准；美国声明后的首个A股交易日才视为可得。15日目标遇休市取最近有效交易日。
- FOMC样本必须按加息、降息、维持分组，历史均值仅作小样本情景证据，不得当成因果结论或确定预测。
- 事件清单中的截图观点属于二手情景。9月4日和9月11日的日期必须在使用前核对官方日历；9月15至16日FOMC沿用项目已登记的官方日历证据。
- 11月只按选举前后和月末复核窗口检查真实流动性数据，不预设“选举后全面下跌”。
- 数据缺失时如实报告，不使用媒体转述或无来源数字补齐。

# 静态托管边界

> **正式保护口径（2026-09-13确认）**：正式方案为B0207每28天完整调仓＋Agent V70看空保护＋单标的连续持有期高点回撤10%止损＋保护资金回投其他原有持仓。V70新看空区间参考减持70%；持有期高点回撤严格超过10%时清仓100%。保护卖出款按其他原有持仓市值比例回投，没有合格接收标的时才留现金，真实执行仍由用户确认。

`server.py` 仅托管项目目录中已经冻结的 `scripts/*.html` 报告和 `app/assets/*` 资源，不提供 API，不读取行情，不导入分析模块，也不会修改报告。项目根目录、`数据/`、状态文件和源码目录均被服务层拒绝访问，并禁用目录浏览。

Python可以离线计算日K、周K客观参数、冠军仓位和B0207机械基线，但不得输出Agent保护建议、用户最终目标或实际成交。候选生成器只冻结日周DIF一二阶、MA5/10/20/60、RSI、量能和20/60日强弱等客观证据；Agent独立填写结构、动量和动作，发布器按`agent-multi-parameter-v3`检查自洽性。只有用户明确确认后，离线发布器才能把冻结数据写入报告JSON和单文件HTML。网页和本地服务器均不得重新计算。

展示名称统一为`B0207周期基线`、`B0207当前周观测`、`当前真实持仓`、`Agent保护后`。最后一列表示实施所列保护建议后的假设组合，必须注明保护起点、拟减持比例和现金变化；未经成交确认不写成真实持仓。内部`agent_recommendation`字段和历史记录类型保留兼容，不更名、不重写历史研究结果。
正式配置采用B0207每28天完整调仓；Agent周期中只审查已有持仓的V70看空保护及持有期高点10%止损，保护资金按其他原有持仓市值比例回投，没有合格接收标的时才留现金。规则或展示更新不记录成交，用户确认保持份额时保留现有持仓。
